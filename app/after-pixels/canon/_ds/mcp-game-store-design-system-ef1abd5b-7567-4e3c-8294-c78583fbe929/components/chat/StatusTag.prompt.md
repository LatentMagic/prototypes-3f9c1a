StatusTag holds one game status: In progress, Solved, Escaped, Out of guesses. Block type `status`.

```jsx
<StatusTag tone="won">Escaped</StatusTag>
{type:'status',tone:'live',label:'In progress'}
```

- One or two words. The tone says how it went; the word says what happened.
- It is the chat's version of Tag: Tag is for the dark shop surface, StatusTag for the light chat.
