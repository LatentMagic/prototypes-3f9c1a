# Delve session page: the loss mark

How a Delve run lost with no roll or use in its last room is marked. Each link opens one canvas; its tabs hold the versions. Frozen: the plain cross (4) was picked and is built into canon.

Open each at `http://localhost:4793/app/after-pixels/explorations/delve-session-loss-mark/index.html?state=<id>`:

1. `delve-story-fall-canvas`: a run killed by a story turn, drawn three ways.
2. `delve-overrun-canvas`: a run lost to the threat filling up, by what filled it.
3. `delve-loss-opens-canvas`: the cross opens like a die, showing the turn that ended the run. Parked for engine work.
4. `delve-plain-cross-canvas`: the cross drawn plain or in a die outline. Picked: the plain cross.
