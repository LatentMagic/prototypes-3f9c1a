# Copy rules

The design system holds no copy rules. Read them in the monorepo (`LatentMagic/monorepo`) before you write any product string:

- The voice of the whole shop: `specs/projects/mcp-games/ui.md`, under Voice.
- The rules for the words on each page written for each game (the product page, the game card, the game page in the Library and the session page): `specs/projects/mcp-games/pages/`.

The layout of those pages is in [page-patterns.md](page-patterns.md).
