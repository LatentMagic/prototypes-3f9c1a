# Logo look-alike hunt: logo-4 (three teal squares + amber circle, 2x2)

Not legal advice. This is a desk search, not a trademark clearance.

## Method and limits (read first)
- Tools: WebSearch (text only) and WebFetch (text only). Neither can see images. No reverse image search was run. No trademark register (UKIPO, EUIPO, USPTO, WIPO) was searched.
- Where a mark is "described", it is from SVG path data or page text, noted per item. Anything I could not source is listed under "Not checked", not guessed.
- Mark under test: 2x2 grid with gaps; top-left, bottom-left, bottom-right = teal #328A88 squares; top-right = amber #E5A63B circle of the same width.

## Real look-alikes found

### 1. Material Symbols "widgets" icon (Google) - closest on arrangement
- What: three axis-aligned squares (top-left, bottom-left, bottom-right) plus a 45-degree rotated square (diamond) in the top-right cell. Read from the SVG path, `M16.65 13L11 7.35l5.65-5.65l5.65 5.65zM3 11V3h8v8zm10 10v-8h8v8zM3 21v-8h8v8z`: https://api.iconify.design/material-symbols/widgets.svg
- Arrangement: the same cell layout as logo-4 (the odd cell is top-right, other three are squares). Only the odd shape differs (diamond vs circle). Rating: **near-identical on arrangement**.
- Colour: monochrome (currentColor). Different from teal/amber. Field: generic Android/Google UI glyph for "widgets"; not a trademark, but a stock icon users meet daily.
- Rating overall: **clearly similar** (near-identical structure, different odd shape and colour). Weakness is "looks like a stock icon", not infringement.
- Also: the MDI "widgets" icon (https://api.iconify.design/mdi/widgets.svg) is the same family: a square top-left, diamond at top-right, squares below. Path read as that shape; the fetch tool's prose description was unreliable, so treat as same-family. Rating: same family only / clearly similar.

### 2. Microsoft logo (and Windows) - arrangement family
- What: four equal coloured squares (blue, yellow, green, red) forming a larger square with gaps, designed 2012 by Jason Wells. Source: https://1000logos.net/microsoft-logo/ (the page mentions no circle variant).
- Arrangement: 2x2 squares with gaps, all four squares. Logo-4 differs by one cell. Colour: unrelated. Field: software and a games/software store (Microsoft Store, Xbox), so field overlaps.
- Rating: **clearly similar** on silhouette (a 2x2 square grid with gaps reads as "Microsoft" first, and swapping one cell for a circle may read as a Microsoft knock-off or a "missing window"), different on colour. Microsoft Store itself: described as a shopping bag carrying the Microsoft logo (https://www.techradar.com/how-to/how-to-use-the-microsoft-store-in-windows-11), so a software store in the same field carries a 2x2 square grid.

### 3. Twilio - same family only
- What: a red circle containing four white dots in a 2x2 grid (from a design-site summary: https://www.designyourway.net/blog/twilio-logo/). Colour red. Field: communications software.
- Rating: **same family only** (2x2 plus circle idea, opposite construction).

### 4. Generic 2x2 "grid / squares four" UI icons
- Phosphor "squares-four": four rounded squares in a 2x2 grid (SVG read at https://api.iconify.design/ph/squares-four.svg). Rating: **same family only** (all squares, outlined, rounded).
- A stock-vector "app widgets" illustration, four squares joined like a puzzle: https://stock.adobe.com/images/vector-illustration-of-four-squares-are-connected-by-a-puzzle-to-form-one-large-square-symbol-of-app-widgets-icon-of-widget-panel/962366097 (title only). Same family only.

## Checked and ruled out (no 2x2 square-plus-circle mark found)
- Foursquare: current logo is wordmark only; earlier was a map pin with F (https://1000logos.net/foursquare-logo/). Not a squares mark.
- Square / Block: filled black square, or concentric rounded squares (https://fabrikbrands.com/square-logo-history-square-payment-logo-symbol-and-evolution/). Not a grid.
- Epic Games: flat badge with lettering, monochrome (https://1000logos.net/epic-games-logo/). Not similar.
- Puzzmo: search results gave an orb cartoon, no mark description. Inconclusive.
- NYT Games: no mark description surfaced. Inconclusive.

## Searches that found nothing
"three squares one circle logo", "2x2 grid logo circle", "game store logo four squares grid one circle teal amber": no named brand with three squares + one circle in a 2x2. Absence in text search is weak evidence only, since logo similarity is visual.

## Closest three
1. Material Symbols / Android "widgets" glyph: same layout, diamond vs circle. Clearly similar (near-identical arrangement).
2. Microsoft four-square logo (and Microsoft Store/Xbox context): 2x2 squares with gaps, same field. Clearly similar on silhouette.
3. Twilio four-dots-in-a-circle, and generic grid icons: same family only.

## Single change that moves it furthest
Break the 2x2 grid itself. Both closest hits depend on "four equal cells in a square block with gaps". Options in order of effect: (a) set the circle off-grid, overlapping or breaking out of its cell so the block is no longer a clean four-cell grid; or (b) make the circle clearly larger or smaller than a square. The least costly, one change: let the amber circle overhang its cell (centred on the gap corner), so the mark stops reading as "widgets" or "Windows with one pane swapped".
Changing colour alone would not help: both near hits are monochrome or multicolour and colour was never the overlap.
