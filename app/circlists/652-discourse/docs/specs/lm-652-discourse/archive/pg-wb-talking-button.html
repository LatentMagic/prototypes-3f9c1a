Five ways to put a talking control in the top bar

The popover is settled. The question is the button: what it looks like, where it sits, and how it lives beside circle settings without the bar reading as clutter. Every direction uses the boxed control vocabulary the bar already has — 8px radius, 1px border, 40px tall — and the sage rule as its only mark. No brand mark, no new icon family. Each is drawn idle (nothing talking) beside changed (three cards talking), in both the web bar and the app bar, because the app bar has no gear to sit beside.

B1Twinned box, left of settings
A second box in the right corner, identical in shape to circle settings, carrying the sage rule and the count and nothing else. No word, no icon — the rule is the circle's mark for "something was said here", and the number says how much. Costs: two boxes in one corner. On the web bar the pair reads as a toolbar, and settings loses its status as the only thing there. In the app bar there is no gear, so the box stands alone at the right end and its "beside settings" logic evaporates.

B2One box, split in two
Not two controls but one object with two halves, divided by a hairline: the count on the left, the gear on the right. The corner keeps a single silhouette, and the count is plainly part of this circle's chrome rather than a stray thing parked next to it. Costs: a split control is a new pattern for the app, and the two halves do unrelated things, which is exactly what split buttons are criticised for. When nothing is talking the left half must vanish and the box changes width — the corner moves. In the app posture there is no gear here at all, so the split cannot exist and it falls back to B1.

B3Nothing new: the count rides the gear
No second control anywhere. Circle settings carries a small sage count, and pressing it opens a short menu whose first row is the talking list and whose second is settings. The corner never changes shape, and the bar gains no clutter at all. Costs: settings becomes two taps to reach, and a gear that opens a menu is a lie about what the gear is. The count also has to sit as a badge on the glyph — the one shape the earlier round ruled out for looking like an alert.

B4Boxed, straight after the name
Same box, other end of the bar: it follows the circle's name, so it reads as a fact about this circle rather than a tool for operating it, and the list drops directly beneath it. It is identical in both postures, because the name is the one thing every top bar has. Costs: the bar now has a control at each end and a truncating name between them, so a long name loses characters to make room. It also puts a pressable box in a slot that has only ever been a label.

B5The name gains a second line
No horizontal room is taken at all. The name slot becomes two lines — the circle's name, and under it the sage rule with a short line of words — and the whole slot is the control. The bar is 56px tall and the name occupies one line of it, so the space is already there. Costs: the bar's height stops being a fixed frame for one line of text, and the second line only exists sometimes, so the name shifts up when something starts talking. Words return here, and a word has to be chosen.
