The mark — at sizes (one asset, every context)

Opaque sage halo · green disc · thin white ring. The opaque halo reads at every size on any background — so the same mark serves app, lockup, and favicon.

The tab favicon is the mark — bare, on transparency, full size (tested on light and dark tabs). The one exception is the installed app icon (iOS/Android), which places the same frozen mark on an opaque cream ground, held smaller, because those surfaces can't control the background (see §2).

Notification icon — the mark, badged, in tabs
CirclistsCirclists
CirclistsCirclists

Resting on the left, notification on the right, both at true tab size. The mark keeps its full presence and gains an emerald badge low-right, drawn in the mark's own vocabulary — the same #FFFFFF keyline weight as the white ring. It deliberately breaks the halo silhouette, which is what makes it catchable out of the corner of your eye at 16px; tucked inside the halo it would disappear. A state, not a redrawing — swapped in while something waits, swapped out when it doesn't. Static always: no motion belongs in a tab (see §2).

Notification badge — the mark as a silhouette (Android notifications)

Android shows the badge using only its shape and applies its own tint (dark on a light header, light on a dark one, as mimicked here). The halo and disc are solid and the white ring is cut out as a gap, so the mark survives in one colour. The file is black on transparency; never recolour it or add a ground (see §2).

Rasters — the mark for non-SVG surfaces (scripts/build_rasters.py)

favicon.ico packs 16·32·48 for classic browser tabs (transparent, full mark); the PNGs cover modern <link rel=icon>. iOS home-screen (180) and PWA (192/512) carry an opaque cream ground with the mark held smaller — the installed-icon exception. For a transparent raster mark (avatars, email, social), take mark/circlists-mark-512.png; the wordmark and lockup ship the same way, at 1024 and 2048 wide, beside their SVGs. All rendered from that one source, supersampled.

Native app icons — Android + iOS (assets/native/)

The native app takes the installed icon as it is: the frozen mark, halo at 72% of the visible tile, on cream. Shown here as each OS masks it. Where an OS themes the icon (Android's themed icons, iOS's tinted appearance), it gets the notification badge's silhouette, because both read one channel. Android takes the shape and iOS takes the brightness, so the iOS file is white on black and the system adds the tint. iOS's dark appearance is the full mark on transparency over the system's dark ground (see §2).
