# Archived playgrounds

Superseded rigs, kept for reference. **The only live playground is
`discourse-playground-v4.html` at the project root.**

Nothing here runs from this folder — `<script src>` paths are
project-root-relative and the module files moved with the rigs. To run one, move
it and its modules back to their original paths.

| Folder | Topic | Where the spec lives now |
|---|---|---|
| `discourse/` | Discourse v1, v2, v3 (see its own README) | `docs/specs/discourse/` — v4 is live |
| `liveliness/` | The arrival grammar (`pg-live-*`) | **The app is the spec** — `app/liveliness.jsx`; see `docs/specs/lm-593-liveliness/` |
| `tab-arrival-signal/` | Browser-tab arrival, three rounds | Decided, not built — `tab-arrival-signal-pack/` |

Loose files at this level are older one-off option studies from before the
per-topic folders.
