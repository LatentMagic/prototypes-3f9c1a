## What was built
The build record (files, mechanics, the calls made and why) is in `handoff.md` in this folder. Changes since it was written:
- Hit line's vertical spacing: `ActiveMatchLine` (`app/feed-history.jsx`) uses `marginTop: calc(17px - var(--circ-feed-pad-top, 16px))`, which cancels the feed column's per-posture top padding (28px desktop, 16px mobile). Measured by glyph ink, 33.5px above and below at 390/768/1327. Joe's rule: done only when equal on both.
- "Include them" is a styled text button (it had rendered as a browser-default grey box).
- Saved in the filter panel swaps `bookmark` / `bookmark-filled` by state, like Watching (`app/feed-lens.jsx`, `LensFilterFace`).
- Search's no-match support line: "Search looks at a card’s title, source and description, and who added it." (Joe's copy; curly apostrophe — a straight one broke the string literal.)
- Search now indexes `item.description` (`app/feed-search.jsx`, `circSearchMatch`; header rule updated). Descriptions are meta only — never rendered.
- Seed: `CIRC_SEED_DESC` in `app/seed-data.jsx`, two per real circle, exported as `CircSeed.SEED_DESC`. `app/main.jsx` backfills them onto persisted state on load, since saved data predates them. Go pipelines card seeded `saved: true`.

## Traps
- Persisted state (`circ_state_v13`) outlives seed changes. New seed fields need a load-time backfill, or they won't show for anyone with saved state.
- Spacing "looks equal" means measured by glyph ink, not box edges, at both postures.
