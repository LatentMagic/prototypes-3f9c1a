# Archived discourse playgrounds

Superseded rigs. **The live playground is `discourse-playground-v4.html` at the
project root** (`docs/specs/lm-652-discourse/pg-d4-*.jsx`).

These are kept for reference only. They will not run from here — their `<script
src>` paths are project-root-relative (`app/*`,
`docs/specs/lm-652-discourse/pg-*.jsx`), and their module files moved with them. To run
one, move it and its modules back to their original paths.

| Files | What it was |
|---|---|
| `discourse-playground.html`, `pg-disc-*.jsx`, `discourse-playground-standalone.html` | **v1** — eight structurally distinct directions. The rig that worked; the source of v4's variety. |
| `discourse-playground-v2.html`, `pg-d2-*.jsx` | **v2 — rejected.** Folded the directions into one "spine" and narrowed the question to continuation. Its record/table components were salvaged into v4. |
| `discourse-playground-v3.html`, `pg-d3-*.jsx` | **v3 — rejected.** Twelve playable versions over the same single mechanism. |

Why v2 and v3 failed: `docs/specs/lm-652-discourse/postmortem-2026-08-03-discourse.md`.
