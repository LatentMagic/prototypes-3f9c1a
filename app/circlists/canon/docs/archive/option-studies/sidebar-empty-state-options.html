The rail when you have no circles

Shown against the real Chrome, which already carries the whole empty state — the heading, the primary Create a circle button, and the invite line. So the rail's only job is to not read as broken. That rules out a second mark (the lockup's already up top — a hat on a hat), a second big CTA, and bordered notes that float rather than integrate. What currently breaks it: the Circles label sitting over nothing.

The heading over an empty region is the thing that looks broken — so remove it. With no circles the rail is just the mark, New circle, and your account. Nothing labels an empty space, so nothing reads as missing. The label returns the moment you have one circle.
