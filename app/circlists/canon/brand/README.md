# Circlists brand — directory guide

Entry point for the brand directory. What's here and how it fits. The product it dresses: [circlists.md](../circlists.md).

- **[circlists-brand.md](circlists-brand.md)**: the brand spec. It restates the palette and type from the prototype's `tokens.css` and describes the mark, wordmark, lockup, icons and motion. Hand-written; the checks in `scripts/check_pack.py` compare it with the scripts and the prototype's `tokens.css`.
- **`circlists-brand.html`**: the visual board, one page, generated. Start here; it shows every asset in context. Tabs: Logo, Icons, App icons, Motion, Colour, Type.
- **[assets/](assets/)**: the shippable output, one directory per thing: [mark/](assets/mark/) · [wordmark/](assets/wordmark/) · [lockup/](assets/lockup/) each hold the SVG and its PNG exports; [icons/](assets/icons/) holds the favicon, notification and installed-icon set; [native/](assets/native/) holds the Capacitor inputs, Android themed layer and iOS dark and tinted icons; [motion/](assets/motion/) holds the animated treatments (pulse, spinner, micro: hand-authored sources, checked by `scripts/build_motion.py` and inlined on the board's Motion tab) and [circlists-motion.md](assets/motion/circlists-motion.md), the rules for using them. Validate motion in a real browser: a headless screenshot reports working motion as dead.
- **[scripts/](scripts/)**: the generators and checks. [scripts/README.md](scripts/README.md): everything under `assets/` (except the hand-authored `assets/motion/` SVGs) and the board file are generated by `scripts/build_all.sh`; never hand-edit the generated ones. `scripts/brand_tokens.py` holds every value once, and `scripts/check_pack.py` checks them against the prototype's `tokens.css` and the spec's numbers and file list against `assets/`.
