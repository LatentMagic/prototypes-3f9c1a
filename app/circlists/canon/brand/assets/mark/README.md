# Mark

The canonical Circlists mark — three concentric circles, transparent, no ground. Source for every icon derivative. Geometry and colours: [../../circlists-brand.md](../../circlists-brand.md) §2.

- `circlists-mark.svg` — reach for this by default.
- `circlists-mark-512.png` · `circlists-mark-1024.png` — the raster exports of the SVG: transparent and square. The halo is opaque, so it holds on any ground.
