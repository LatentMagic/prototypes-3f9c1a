# Lockup

Mark left of the wordmark, centred on its cap-midpoint. Composed deterministically from the mark and wordmark — never hand-edited. Spec: [../../circlists-brand.md](../../circlists-brand.md) §4.

- `circlists-lockup.svg` — ink, for light grounds. Reach for this by default.
- `circlists-lockup-reversed.svg` — cream, for dark grounds.
- `circlists-lockup-1024.png` · `-2048.png`, and the same two for `-reversed` — transparent, 4.44:1. The number is the width.

Regenerated by [../../scripts/build_lockup.py](../../scripts/build_lockup.py) (SVG) and [../../scripts/build_rasters.py](../../scripts/build_rasters.py) (PNG). Overview: [../README.md](../README.md).
