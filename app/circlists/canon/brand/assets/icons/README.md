# Icons

The favicon and installed-icon set: the mark composed on a ground, at the fixed sizes browsers and mobile OSes dictate. Not general-purpose exports — for a plain raster mark take [../mark/circlists-mark-512.png](../mark/circlists-mark-512.png). Why each takes the ground and shape it does: [../../circlists-brand.md](../../circlists-brand.md) §2.

- `favicon.svg` · `favicon.ico` · `favicon-16.png` · `favicon-32.png` — browser tab. Transparent, mark at full size.
- `favicon-notification.svg` · `favicon-notification-16.png` · `favicon-notification-32.png` — the notification icon: the mark plus the arrival badge, swapped into the tab while something waits. Transparent, full size.
- `notification-badge.svg` · `notification-badge-96.png` — the notification badge: the mark as a black silhouette on transparency, with the white ring cut out as a gap. Pass the 96px PNG as the Web Notifications `badge`; Android uses only its shape.
- `apple-touch-icon.png` (180) — iOS home screen. Opaque cream, hard square; iOS rounds it.
- `icon-192.png` · `icon-512.png` — PWA `any` (desktop). Cream, corners rounded into the file.
- `maskable-icon-192.png` · `maskable-icon-512.png` — PWA `maskable` (iPhone + Android). Opaque cream, hard square; the OS masks it.
- `app-store-icon-1024.png` — Apple App Store listing icon (1024×1024). Opaque cream, hard square, no alpha channel (Apple rejects one); Apple rounds it. Same composition as `maskable-icon-512.png`.
- `play-store-icon-512.png` — Google Play listing icon (512×512). Opaque cream, hard square, a 32-bit PNG with every pixel opaque, as Play asks; Play rounds it and adds the shadow. Not `icon-512.png`: that one has transparent rounded corners.

The native app's own icons (Android adaptive and themed layers, iOS dark and tinted) live in [../native/](../native/README.md).
