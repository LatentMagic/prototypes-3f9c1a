# Brand assets

The shippable output. Regenerated by [../scripts/](../scripts/README.md); the spec is [../circlists-brand.md](../circlists-brand.md).

One directory per thing — the mark, the wordmark, the lockup, the web app icons, and the native app icons. Each logo directory holds **both formats**: the SVG (the source of truth, shippable as-is) and its PNG exports.

**Reach for the SVG by default.** The PNGs exist for surfaces that won't take vector — avatar and profile uploads, email signatures, social posts, slide decks. Their geometry is the SVG's, rendered straight to raster on transparency; nothing is added.

The PNG number is the **long edge** — square for the mark, width for the wordmark and lockup. The smaller size is the everyday upload; the larger covers print and retina decks.

## `mark/`

- `circlists-mark.svg` — the mark; also the favicon / app-icon source.
- `circlists-mark-512.png` · `circlists-mark-1024.png` — transparent square. The halo is opaque, so it holds on any ground; this is the avatar upload.

## `wordmark/`

- `circlists-wordmark.svg` · `circlists-wordmark-reversed.svg` — wordmark, ink (light) / cream (dark).
- `circlists-wordmark-1024.png` · `circlists-wordmark-2048.png`, and the same two for `-reversed` — transparent, 3.70:1.

## `lockup/`

- `circlists-lockup.svg` · `circlists-lockup-reversed.svg` — mark + wordmark, ink / cream.
- `circlists-lockup-1024.png` · `circlists-lockup-2048.png`, and the same two for `-reversed` — transparent, 4.44:1.

## `icons/`

The favicon and installed-icon set — the mark composed on a ground, at the fixed sizes the browser and the OS dictate. Not general-purpose exports; for a plain raster mark use `mark/circlists-mark-512.png`.

- `favicon.svg` — tab favicon: the bare mark on transparency, full size.
- `favicon.ico` — 16·32·48, classic browser tab (transparent, full mark).
- `favicon-16.png` · `favicon-32.png` — modern `<link rel=icon>` (transparent, full mark).
- `favicon-notification.svg` · `favicon-notification-16.png` · `favicon-notification-32.png` — the notification icon: the mark plus the arrival badge, swapped into the tab while something waits.
- `apple-touch-icon.png` — 180, iOS home screen. Opaque cream ground, mark ~72%, hard square (iOS rounds it), supersampled (the installed-icon exception).
- `icon-192.png` · `icon-512.png` — PWA manifest `any` (desktop: macOS dock, Windows). Cream ground, **corners rounded into the file** (transparent outside), mark ~72%, supersampled — desktop shows the tile unmasked, so we bake the rounding.
- `maskable-icon-192.png` · `maskable-icon-512.png` — PWA manifest `maskable` (iPhone + Android). Opaque cream ground, **hard square**, mark ~72% (safe zone), supersampled — the phone OS masks the tile itself, so it must stay square.
- `app-store-icon-1024.png` — Apple App Store listing. Opaque cream, hard square, no alpha channel.
- `play-store-icon-512.png` — Google Play listing. Opaque cream, hard square, 32-bit with every pixel opaque.

## `motion/`

The animated treatments of the mark, each with its motion and reduced-motion fallback inside the file. Hand-authored sources (not generated; `build_all.sh` leaves them), checked against the tokens by `scripts/build_motion.py`.

- `circlists-pulse.svg` — the idle breathing mark.
- `circlists-spinner.svg` — the loading state.
- `circlists-micro.svg` — the ~10 px live-signal dot.
- [motion/circlists-motion.md](motion/circlists-motion.md) — the values and how a surface consumes them.

## `native/`

The native app's icon sources (rasters 1024 square), same composition as the installed icon. Full detail and where each goes: [native/README.md](native/README.md).

- `icon-only.png` · `icon-foreground.png` · `icon-background.png` — the `@capacitor/assets` inputs: iOS icon and Android legacy icons, Android adaptive foreground, Android adaptive background.
- `ic_launcher_monochrome.xml` · `icon-monochrome.png` — the Android themed-icon layer: the mark as a silhouette, vector drawable plus a raster preview.
- `ios-icon-dark.png` · `ios-icon-tinted.png` — the iOS dark and tinted appearances.
