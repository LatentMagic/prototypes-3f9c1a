# Wordmark

"Circlists" outlined from Inter Bold, with the green tittle on the second `i`. Two files, geometrically identical — only the ink colour differs. Spec: [../../circlists-brand.md](../../circlists-brand.md) §3.

- `circlists-wordmark.svg` — ink, for light grounds. Reach for this by default.
- `circlists-wordmark-reversed.svg` — cream, for dark grounds.
- `circlists-wordmark-1024.png` · `-2048.png`, and the same two for `-reversed` — transparent, 3.70:1. The number is the width.

Regenerated by [../../scripts/wordmark-outline.py](../../scripts/wordmark-outline.py) (SVG) and [../../scripts/build_rasters.py](../../scripts/build_rasters.py) (PNG). Overview: [../README.md](../README.md).
