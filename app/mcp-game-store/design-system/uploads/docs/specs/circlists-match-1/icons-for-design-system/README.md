# Icons for the design system

Three line icons (1.75 stroke, square caps, mitred joins, 24px, currentColor), ratified by the owner on 2026-10-07 for the design system.
Copy them into the design system's `assets/icons/line/` and register them with `Icon`. Each one still needs a solid drawing to match the rest of the set.
- `mail.svg`: Continue with email
- `logout.svg`: Sign out
- `card.svg`: Update payment card
