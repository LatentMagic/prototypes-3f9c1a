## Learnings

- The preview's "32 referenced files not found" warning is the known false positive (four levels of `<base>`). The page renders with tokens and the real top bar. Checked by screenshot: options 4, 5 and 6 at desktop width, the Share panel with Copy → Copied, option 6's case opening in place, and option 4 for No Pass and Pass ended.
- **Phone width was not checked.** Layouts switch at container width 900 (`.cb4`, `.cb5-row`, `.cb6`). Below that, 5's table folds to title + status with a meta line, and 4's and 6's side columns stack above or below.
- Sticky side columns are on only when the window is at least 900px tall, because 6's panel is taller than a short window.
- The DS `Popup` window is 380px wide, and its actions sit in a two-column grid. A lone action leaves half the row empty, so the panel pairs Close with Copy.
- localStorage key `pg_library_casebook_v1`, reset to `{opt:'4', viewer:'pass', open:true}`.
- Possible GOTCHA (not proposed to the user yet): the Clipboard API fails silently in the preview iframe; use a textarea fallback inside the click.
